Orca is the ADE for working with a fleet of parallel agents. Run any coding agent with your own subscription. Available on desktop, mobile and remote runtime.

这是一款跨平台的 AI 编程智能体编排工具，能够让 Claude Code、Codex 等分别在独立的 Git 工作树中并行运行，并通过同一界面统一管理。它能将同一个提示词同时发送给多个 Agent，对比结果后合并最优方案。还可通过手机 App 查看进度、接收通知和发送指令，适用于 Windows、macOS 和 Linux。
