作者 virgiliojr94 Python ★ 34.3k Fork - 最近更新 推荐人 卤蛋

Turn any technical book PDF into a Claude Code skill — ready to study, reference, and use while you work.

这是一款可以将技术书籍和文档转化成 Agent 技能的工具，让 AI 编程助手按需加载并基于原书内容回答。它会自动生成 SKILL.md、按章节拆分的文件、术语表和速查表，让 Token 消耗比直接把整本书塞进上下文少 20-50 倍，支持 PDF、EPUB、DOCX 和 Markdown 等文件。
