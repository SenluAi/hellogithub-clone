Private EMail Server

该项目是用 Go 编写的个人邮件服务器，仅需一台服务器和域名，就能部署自己的域名邮箱。它开箱即用、体积小、占用资源少，内置邮件收发服务和 Web 管理界面，支持 SMTP、POP3、IMAP 协议，以及多域名、多用户和 HTTPS 证书自动续期等功能。
