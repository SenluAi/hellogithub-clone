统一管理 AI 技能包的工具

xingkongliang/skills-manager
作者 xingkongliang Rust ★ 5.8k Fork - 最近更新 推荐人 卤蛋

A lightweight desktop app to manage, sync, and organize AI agent skills across 50+ coding tools — Claude Code, Codex, Cursor, Copilot, Gemini CLI, and more.

这是一款跨平台的 AI 智能体技能管理工具，可将散落在不同工具中的技能集中存入本地仓库，并一键同步到 Claude Code、Codex、Cursor 等工具。它支持从 Git 仓库、本地文件夹、压缩包和 skills.sh 市场安装技能，还提供技能组合预设、项目级管理、上游更新检测和标签筛选等功能，适用于 Windows、macOS 和 Linux。
