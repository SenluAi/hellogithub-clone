Making an ESP32-based quadcopter from scratch

该项目是基于 ESP32 的四旋翼无人机，内含 3D 打印机架、接线图和飞控固件。它通过 Wi-Fi 或 ESP-NOW 使用 MAVLink 协议通信，可用 USB 手柄、遥控器或手机操控，并提供无线命令行调试、Gazebo 仿真和用于自动飞行的 Python 库。
