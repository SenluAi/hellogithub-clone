这是图吧工具箱基于 WinUI 3 全新重构的版本，一款由社区驱动、深度契合 Windows 11 设计美学的现代化工具箱。它不仅确保你始终使用最新版本的工具，还集成了更加丰富的实用功能，更可满足高度自定义的个性化需求。

该项目是采用 C# 和 WinUI 3 开发的 Windows 装机工具箱，集成硬件检测、装机助手、网络诊断和垃圾清理等功能。
